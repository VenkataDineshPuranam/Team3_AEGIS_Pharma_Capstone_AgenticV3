Nature of each repository

These are not three versions of the same running app. V1 is a workshop challenge. V2/V3 are a separately built agentic system (ADR-002: zero V1 code reuse).

V1 — brownfield capstone

Workshop-Ready v2 challenge: 84 injects, 139 CSVs, 32 knowledge docs, defective starter/ code. Team 3 work lives in submission/: 12 ADRs on paper, submission/src/ is contracts.py + policy_guard.py + __init__.py, 35 tests, Next.js 15.5 mock cockpit (USE_MOCK = true). demo.py imports workflow_batch / workflow_pv / workflow_supply — those files are not in the tree.

V2 — agentic Control Center

Spec-driven 21-stage rebuild. FastAPI hosts six LangGraphs. Next.js 16 is wired to real APIs (login, queue, decide, coverage). Neo4j + Redis + SQLite. Nine ADRs accepted. Chaos folder is a three-line README. No docker-compose. Foundry is a commented .env.example line; get_llm() defaults to Anthropic.

V3 — current tree (this repo)

Strict superset of V2 source — nothing V2 had was dropped. Adds AzureFoundryLLM (default provider), compose + scripts/bootstrap.sh, injectable ADR-007 chaos drills, SQLite thread-safety and Dockerfile fixture fixes, GitHub Pages, and the comparison / system-map / high-level / low-level architecture HTML.
