AEGIS-PHARMA · V3

A governed multi-agent AI system for pharma operations

Six LangGraph-orchestrated workflows — GxP batch review, pharmacovigilance intake, supply-shortage planning, preclinical research review, clinical trial integrity, and regulatory submission completeness — with human-in-the-loop approval, prompt-injection defense, and an AI-BOM enforced server-side, not just documented.

Quickstart

git clone https://github.com/VenkataDineshPuranam/Team3_AEGIS_Pharma_Capstone_AgenticV3.git
cd Team3_AEGIS_Pharma_Capstone_AgenticV3
./scripts/bootstrap.sh
# fills in .env from the template, installs backend + frontend deps,
# seeds demo data once you've added your NEO4J_*/ANTHROPIC_API_KEY values
git clone https://github.com/VenkataDineshPuranam/Team3_AEGIS_Pharma_Capstone_AgenticV3.git
cd Team3_AEGIS_Pharma_Capstone_AgenticV3
cp .env.example .env   # fill in ANTHROPIC_API_KEY at minimum
docker compose up --build
docker compose --profile seed run --rm seed   # first run only
# API on :8000, web UI on :3000
# Backend
pip install -r requirements-dev.txt
python3 -m services.integration.seed_users
uvicorn services.api.main:app --port 8000

# Frontend (separate terminal)
cd apps/web && npm install && npm run dev

Open http://localhost:3000 — demo credentials for all ten roles are in docs/governance/demo_login_credentials.md.

What's inside

Six governed workflows

Batch review, PV intake, supply planning, preclinical review, trial integrity, submission completeness — each a LangGraph graph with its own eligibility and severity ladder.

HITL, for real

Server-side authorization on every decision, live severity timers, and escalation notifications — display-only, never auto-approves (BC-12).

Prompt-injection defense

Input and output scanning bracket three structural layers that make prohibited actions unrepresentable, not just discouraged.

AI-SBOM

CycloneDX 1.6 ML-BOM, verified at CI and at container startup — a tampered tool contract stops the app from booting.

Record Assistant

A chat panel on every page that explains a record in plain language — the model writes prose, a deterministic layer computes every fact and next step.

CI/CD

GitHub Actions: lint/test/build on every push, tagged deploys to Azure Container Apps, and a nightly automated red-team sweep.
